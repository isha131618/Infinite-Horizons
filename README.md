# Infinite Horizons 🌌

Infinite Horizons is a desktop application built with Electron that allows users to explore and learn about planets and the universe through an interactive interface.

## Features

* 🌍 Explore different planets and celestial bodies
* 🖼️ Interactive and visually appealing interface
* 📚 Dedicated sections for information and resources
* 💻 Standalone Windows application

## Installation

### Option 1: Download the Application

1. Clone the repository:

```bash
git clone https://github.com/isha131618/Infinite-Horizons.git
```

2. Open the `Infinite-win32-x64` folder.

3. Run:

```
Infinite.exe
```

No additional installation is required.
